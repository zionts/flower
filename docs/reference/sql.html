Experimental foundation: unavailable

HOLD, not a released SQL interface. The opt-in native evaluator is compiled only with --features sql. Complete serving-snapshot retention has not been hard-bounded: the native host refuses all SQL operations with SQL_SNAPSHOT_UNBOUNDED even in that build. The default build refuses them with SQL_UNAVAILABLE. There is no test/public bypass. SQLite allocator/operator unit tests are not end-to-end provider-policy conformance.

The source foundation uses real SQLite virtual tables over bounded authorized native candidate pages, never a whole-organization JSON export or persistent replica. Collections are not automatically exposed. Applications must wait for the snapshot/resource/authority/cancellation gates before exposing SQL aliases. Read the repository's SQL.md and src/consensus/records_sql_snapshot.md for the precise limits, evidence, and requirements for opening the gate.

Authority ends before providers

APIContract
SqlReadContextPure collection point reads and bounded declared-index reads, principal/history/codeVersion and certified clock/changesAt. No writes, definer elevation, derived reads, SQL recursion, managed keys, filesystem/network or entropy.
SqlAuthorityContextDedicated pure deployed validation callback. Application auth-row read rights do not flow into providers; users cannot provide an effective principal.
SqlProviderContextDedicated rights-preserving callback, not a derived value. Effective invoker, snapshot, cumulative budgets and data/policy dependencies are retained.
SqlAuthorityRequest{catalog,invoker,purpose}; raw purpose is untrusted. Verify current human authority or a live database-local captured session grant/generation/lease and destination audience.
SqlAuthorityDecision{principal,context,tables} or null from authorize. tables is an explicit logical allowlist, also applied to discovery. Only validated context reaches provider purpose.
SqlProviderInput{source:{name},rows:[{key,value}],purpose}; bounded candidates are already collection-ACL filtered/redacted. SDK decodes JSON keys; native sourceKey columns intentionally retain encoded text.
SqlProjectedRow{sourceRow,cells}; sourceRow is a validated batch-local ordinal. Native mapped columns override placeholders from that exact redacted candidate.
SqlProviderBatch{rows,provenance?}. Provenance is bounded trusted internal evidence; never expose it as human cells/catalogs/errors or log it on failure.

Temporal policy helpers must use clock() and declare every known future expiry with changesAt(). Unknown/polled temporal authority fails closed. Before delivery, the service reauthorizes on current serving state and validates source/policy dependencies and expiry. Agent logging/publication still needs separate atomic current audience/exposure admission.

One-shot typed reads

APIContract
SqlContextQueryContext.sql: query/catalog/explain/cancel. Every exposed SQL method requires cache:false,watch:false; server lookup/coalescing/insertion and watch registration are refused independently.
SqlQueryInput{sql,parameters?,maxRows?,queryId?}; positional parameters, default 100 rows, at most 1000. Query ID is ephemeral, not a row ID or authorization capability.
JsonScalarnull, boolean, finite JSON number or string. Wide exact integers belong in decimal source/tagged cells, not lossy JSON numbers.
SqlCellnull | {integer:string} | {real:number} | {text:string}. Signed-i64 integers stay exact. Nonfinite reals and blobs fail.
SqlResultColumn{name,logicalType?,unit?}. Ordered descriptors preserve duplicate aliases.
SqlResult{columns,rows:SqlCell[][],resultTruncated,warnings,catalogVersion}. A presentation cap can truncate; source/work failures are errors, never partial COUNT/SUM success.
SqlExecution{result,provenance}. Public human aliases return result only; private evidence is for independently reauthorized completion.
SqlCatalogColumnPublic column metadata, omitting physical sourceField/sourceKey mappings.
SqlCatalogInfo{name,catalogVersion,tables,relationships}; authorized logical metadata only. Built-in sql_tables/sql_columns/sql_relationships need no durable mirror.
SqlExplain{catalogVersion,plan:[{detail}],warnings}. Logical plans never expose hidden source names/cardinality.
ctx.codeVersion(): string | nullNative SHA-256 binding to the current validated deployed bundle and schema/policy/catalog generation. Records dependencies. Mutations compare it for anti-replay; old/Node runtimes fail rather than synthesize a hash.

query(catalog,input,purpose?) returns SqlExecution; catalog(catalog,purpose?) returns SqlCatalogInfo; explain(catalog,input,purpose?) returns SqlExplain; cancel(catalog,queryId,purpose?) returns boolean. Cancellation is keyed by freshly verified original/effective principal, purpose, partition and query ID, with permits retained until actual termination.

Trusted one-shot HTTP envelopes add history:{database,incarnation}|null beside revision/value, from the exact native snapshot. Separate requests take fresh snapshots. The Node testDatabase refuses native SQL; the real-server harness must currently confirm the hard HOLD, not claim positive provider conformance.
